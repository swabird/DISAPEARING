# DISAPEARING

Disappearing Animal Species is a static visual atlas of endangered animal posters.

The gallery is split into Russian and English collections by OCR-detected text inside each image, not by filename. The generated OCR output is kept in `data/ocr.tsv`, and the macOS Vision OCR helper is kept in `tools/ocr_classify.swift`.
